A public-services assistant with guardrails on the way in and on the way out. Personal details never reach the model, an agent cannot act without a person saying yes, and every request leaves a trace you can read afterwards.

A request through the pipeline

From sign-in to the audit trail — the same input and output rails, verdict actions, specialist agents, and tools defined in this codebase, laid out as one path a request actually walks through Engine.converse().

solid — deterministic code dashed — a one-shot model call clay — a guardrail gate red — where a request can stop short AGENT a real reasoning step — plans, or is one of the six specialist agents DETERMINISTIC ordinary code, even though the agent chose to call it

Where "agent" actually means something here. Four things are tagged AGENT: the planning step that picks a specialist or a tool, the six specialist agents themselves (agents/supervisor.py), the four tools it can call, and the model call that writes the final draft. Everything else solid is plain code with no model in the loop; everything else dashed is a single classifier call, not a multi-step agent.

Masking is not refusing. The name and phone number are detected and masked, and the request carries on — answered correctly from the Citizen Charter: own agricultural land in the society's area, then pay the admission fee and share capital.
